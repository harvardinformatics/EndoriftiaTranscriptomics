# EndoriftiaTranscriptomics
Code used in data analysis for Mitchell et al. (2024), "Beyond the single pathway: co-expression analysis reveals distinct roles of dual carbon fixation in Riftia pachyptila symbionts," on transcriptomic responses to environmental variation in Candidatus *Endoriftia persephone*, the bacterial symbiont of the deep-sea tubeworm *Riftia pachyptila*. Published in Nature Microbiology 9:1526–1539.
